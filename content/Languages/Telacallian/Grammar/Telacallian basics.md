[[Telacallian]] grammar basics


# Verbs
In Telacallian verbs have a Nahuatl root, example:
```
working > tekeetee
running > motlaloa
swiming > tlamaneloa
```
## to be
The verb "to be" is one of the verbs without a Nahuatl root and instead is `yehuas`

# Nouns
Telacallian nouns have a Latin root, example:
```
cat > feles
house > domus
human > homo
```


# adjectives
lastly in Telacallian adjectives have a Greek root, example:
```
black > melas
happy > eftichizmeno
big > megas
```
in Telacallian a adjective is put before the noun

# Articles
Much like English has the articles "a/an" and "the" Telacallian has "al" and "ra" so if you wanted to say "the cat" or "a cat" you would get:
```
the cat > ra feles
a cat > al feles
```
articles do not change depending on gender or number
# Pronouns
Telacallian personal pronouns are as following

| personal pronoun | Telacallian pronoun |
| ---------------- | ------------------- |
| I                | ni                  |
| you (singular)   | yi                  |
| he               | lis                 |
| she              | kiz                 |
| it               | di                  |
| we               | nis                 |
| you (plural)     | yis                 |
| they             | mis                 |

| posesssive pronoun | Telacallian pronoun |
| ------------------ | ------------------- |
| my/mine            | ne                  |
| your/yours         | ye                  |
| his                | les                 |
| her/hers           | kez                 |
| its                | de                  |
| our/ours           | nes                 |
| your (plural)      | yes                 |
| their/theirs       | mes                 |

| demonstrative pronoun | Telacallian pronoun |
| --------------------- | ------------------- |
| this                  | ma                  |
| that                  | na                  |
| these                 | mas                 |
| those                 | nas                 |

| interrogative pronoun | Telacallian pronoun |
| --------------------- | ------------------- |
| who                   | bo                  |
| whose                 | bos                 |
| what                  | mo                  |
| which                 | no                  |

# Examples
with all of these rules combined we can get sentences like:
```
the big black cat > ra mega melas feles
a happy man > al eftichizmeno vir
I am a big cat> ni yehuas al megalo feles
```
