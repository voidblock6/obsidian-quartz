a guide on how to make names for places, species, people and things in [[Telacallian]]


# Geographical naming conventions for Tellacalia:

1: first part of word is Latin and second part of word is Aztec/Nahuatl

2: merge after after second vowel of first word:
(diphthongs count as 1 vowel.  y is not treated as a vowel here. if only 1 vowel merge after that)

Nebula + Tllali = Nebutlalia

3: remove second l if 2 l's in a row if word gets to complicated to say

4: if word ends with -l add -ia 
Arenea + Tocatl = Arecatlia 

5: if word ends with -i  add -a 
Aranea + Calli = Aracallia

6: if word ends on a different vowel remove it and add -ia
(rare in practice)

7: if u want to name a thing with 3 or more words

1: for every pair of 2 words: create a merged word with the first 2 words and with the last 2 words (rules above apply)

2: for the last word if the count is uneven: Last word is Aztec/Nahuatl

3: if last word ends on a Consonant add -ias

4: if word ends on i add -as
(if it ends on a different vowel remove it and add -is)

Megaloprepis + teotl + tocatl = Megateotlia tocatlias 
# Personal naming conventions for Tellacalian people

1: first part of word is Greek and second part of word is Aztec/Nahuatl

2: merge after second vowel of first word:
(diphthongs count as 1 vowel. y is not treated as a vowel here. if only 1 vowel merge after that)

Arachne + Calli = Aracalli

3: remove second l if 2 l's in a row if word gets to complicated to say

4: if word ends in -l add  -in
Serikon + Tocatl = Seritocatlin

5: if word ends with i add -or
Domus + Tllali = Domutlalior

6: if word ends on a different vowel remove it and add -ior
(rare in practice)

7: if u want to name a thing with 3 or more words

1: for every pair of 2 words: create a merged word with the first 2 words and with the last 2 words (rules above apply)

2: for the last word if the count is uneven: Last word is Latin

3: if last word ends on a Consonant add -io

4: if word ends on i add -o
(if it ends on a different vowel remove it and add -is)

# Naming conventions for species 

1: first word Latin second word is Greek

2: if second word ends on a consonant add -us
(y is a vowel here)

Homo + Lykos = Homo Lykosus

3:  if second word end on a -i add -s
Arachne + Psari  = Arachne Psaris

4: if second word end on a different vowel remove it and add -is
Homo + Gata = Homo Gatis

# Naming conventions for things and objects

1: first word is Greek second words is Latin

2: merge after after second vowel of first word:
(diphthongs count as 1 vowel.  y is not treated as a vowel here. if only 1 vowel merge after that)
Arachne + Sericum = Arasericum


3: remove second l if 2 l's in a row if word gets to complicated to say

4:  if second word ends on a consonant add -um
(if word already has -um do nothing. if word ends on -us remove it and add -um)

Arachne + Nidus = Aranidum 

5: if word ends with -e  add -um

6: if word ends on a different vowel remove it and add -eum
(rare in practice)
Chora + bene = Chorabeneum

7: if u want to name a thing with 3 or more words

1: for every pair of 2 words: create a merged word with the first 2 words and with the last 2 words (rules above apply)

2: for the last word if the count is uneven: Last word is Aztec/Nahuatl

3: if last word ends on a Consonant add -is

4: if word ends on i add -s
(if it ends on a different vowel remove it and add -is)

Chora + Nidus + Tocatl = Choraniduseum Tocatlis

Fun fact: Telacallia comes from the Latin tela wich means web and the Aztec/nahuatl calli which means house, so Telacallia is the house of webs
